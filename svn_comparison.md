#Git vs SVN

1. Почему в Git ветвление "дешёвое", а в SVN — "дорогое"?

В гите ветка это метка на коммит. Лежит локально, для работы ничего делать не надо
В SVN это копия папки проекта на сервере. Для работы её нужно сначала скачать

2. Можно ли в SVN сделать коммит без интернета? Почему?

Нельзя, ибо в SVN вся история хранится на сервере

3. В каких сценариях SVN до сих пор может быть предпочтительнее Git?

- Когда в проекте много больших файлов (картинки, видео, модели для игр).
- Когда нужно запретить двум людям одновременно менять один файл.
- Когда проект огромный, а скачать нужно только одну папку.
- Когда нужно выдавать доступ к отдельным папкам разным людям.
- В старых проектах, которые давно на SVN и переносить их дорого.
